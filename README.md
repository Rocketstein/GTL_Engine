## 공개본 구성 원칙

- C/C++, HLSL, Lua, 빌드 설정과 설명 문서를 중심으로 보존했습니다.
- 폰트, 메시, 텍스처, 머티리얼, 이미지, 오디오, 씬과 패키지 에셋은 제외했습니다.
- 실행 파일, 라이브러리, 심벌, 캐시, 생성 파일과 패키지 복원 결과는 제외했습니다.
- 재배포 조건을 확인한 서드파티 소스와 헤더는 해당 라이선스 고지와 함께 포함했습니다.
- 상용·제한적 SDK와 컴파일된 서드파티 DLL/LIB는 계속 제외했습니다.
- 명시적인 외부 `All Rights Reserved` 표기가 있고 재배포 권한을 확인할 수 없는 소스 파일은 제외했습니다.

따라서 이 공개본만으로는 곧바로 빌드 또는 실행되지 않을 수 있습니다. 필요한 의존성과 누락 범위는 [DEPENDENCIES.md](./DEPENDENCIES.md), 포함된 외부 코드의 고지는 [THIRD_PARTY_NOTICES.md](./THIRD_PARTY_NOTICES.md)를 참고하세요.
